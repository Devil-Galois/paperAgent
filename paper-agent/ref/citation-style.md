# Citation Style Notes

Default policy:

- Keep a single citation style within one paper project
- If the user does not specify a venue, use a simple numeric style in the draft stage
- Store enough metadata in `references.md` so later conversion is easy

## Minimum Metadata Per Reference

- authors
- title
- venue
- year
- DOI or URL if available

## Draft-Stage Recommendation

Inside `draft.md`, use one of these temporary forms consistently:

- numeric placeholder: `[1]`
- author-year placeholder: `(Smith, 2024)`

Inside `references.md`, keep fuller information for later normalization.

## Rules

- Do not cite a source you have not actually used
- Do not invent page numbers
- If a source is only indirectly known, mark it as unverified
- For web sources, prefer official pages over mirrors or reposts
