# Default Academic Paper Template

Use this template for ordinary academic writing tasks unless the user specifies a target venue format.

Before using this template, confirm that the paper type and scope have already been stabilized through `intake.md` and `brief.md`.

## Title

- Prefer a specific title over a broad slogan
- Include the technical object, method, or problem setting

## Abstract

Recommended structure:

1. background and problem
2. gap or limitation
3. method or perspective
4. main findings or expected contributions
5. significance

## 1. Introduction

- background
- importance of the problem
- current limitations
- paper objective
- main contribution or review angle
- section roadmap

## 2. Background or Preliminaries

- core concepts
- notation if needed
- technical assumptions

## 3. Related Work

- organize by problem family, method family, or evaluation setting
- compare approaches instead of listing papers one by one

## 4. Main Body

Choose one mode:

- review/survey mode
  - taxonomy
  - comparison dimensions
  - strengths and limitations
- research-proposal mode
  - problem formulation
  - proposed idea
  - expected mechanism
  - evaluation plan
- technical analysis mode
  - system/model description
  - mechanism analysis
  - tradeoff discussion

## 5. Discussion

- limitations
- bottlenecks
- failure modes
- open questions

## 6. Conclusion

- restate the core answer
- summarize the real contribution
- avoid introducing new claims

## References

- keep citation style consistent
- do not include uncited entries in the final version unless the task is a reading list

## Interactive Use Note

If the user is still deciding the paper angle, do not fill the whole template immediately.

Complete in this order:

1. title candidates
2. introduction skeleton
3. section skeleton
4. only then expand into full prose
